# Population Reporting System

## Project Overview
The Population Reporting System is a software engineering project developed using C# and MySQL. The system is designed to generate and display population statistics for countries, cities, and regions around the world.

## System Features
- View world population reports
- Display country population details
- Search city population information
- Generate continent population statistics
- Database integration using MySQL
- Unit testing support
- Version control using GitHub
