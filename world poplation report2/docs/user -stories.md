# User Stories

## US1
As a user, I want to view all countries ordered by population so that I can analyze population statistics.

## US2
As a user, I want to view cities ordered by population so that I can compare city populations.

## US3
As a user, I want to generate top N populated countries so that I can identify the largest countries.

## US4
As a user, I want to see language statistics so that I can understand language distribution.
