# Use Cases

## Generate Country Report

### Actor
User

### Preconditions
System is connected to the database.

### Main Flow
1. User selects country report.
2. System retrieves country data.
3. System sorts data by population.
4. System displays report.

### Postconditions
Country report is displayed successfully.
